# 🎨 ChurnAlert AI - Frontend

The frontend is a modern React application built with Tailwind CSS, providing a high-performance dashboard for Customer Success Managers.

## 🚀 Features

-   **Risk Dashboard:** Color-coded list of accounts sorted by risk severity.
-   **Detailed Analysis View:** Interactive cards showing usage trends, ticket sentiment, and AI reasoning.
-   **Intervention Workflow:** Inline editor for outreach drafts with approval tracking.
-   **Responsive Design:** Optimized for desktop and tablet views.

## 🛠️ Setup & Installation

1.  Navigate to this directory: `cd frontend`
2.  Install packages: `npm install`
3.  Start development server: `npm run dev`

## 🏗️ Core Technologies

-   **React:** UI framework.
-   **Tailwind CSS:** Premium styling and layout.
-   **Axios:** API communication with the Flask backend.
-   **Lucide React:** Iconography.
-   **Chart.js / Recharts:** Data visualization.

## 📁 Directory Structure

-   `src/components/`: Reusable UI components (AccountCard, RiskTable, etc.)
-   `src/pages/`: Main views (Dashboard, Admin)
-   `src/services/`: API integration logic.
-   `src/hooks/`: Custom React hooks for state management.
